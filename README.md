每个项目将说明适用平台、系统与 SDK 版本、已测试设备、构建步骤、交互方式、第三方素材许可和已知限制。脑机接口功能仅在项目明确说明支持时提供；当前仓库为发布入口，尚无可下载游戏源码或安装包。
